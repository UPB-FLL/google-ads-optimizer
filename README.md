# Google Ads Optimizer

A tool for optimizing Google Ads campaigns through automated analysis and recommendations.

## Project Overview

This project aims to help advertisers maximize their ROI on Google Ads by providing intelligent insights and automated optimization suggestions.

## Features

- Campaign performance analysis
- Budget optimization recommendations  
- Keyword bid management
- Ad copy testing and optimization
- ROI tracking and reporting

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Google Ads API access
- Google Cloud project with appropriate credentials

### Installation

```bash
npm install
```

### Configuration

Create a `.env` file with your Google Ads credentials:

```
GOOGLE_ADS_DEVELOPER_TOKEN=your_developer_token
GOOGLE_ADS_CLIENT_ID=your_client_id
GOOGLE_ADS_CLIENT_SECRET=your_client_secret
GOOGLE_ADS_REFRESH_TOKEN=your_refresh_token
GOOGLE_ADS_CUSTOMER_ID=your_customer_id
```

## Usage

```bash
npm start
```
